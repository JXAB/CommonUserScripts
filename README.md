# CommonUserScripts

常用服务器一键脚本集合。

| 目录 | 说明 | 一键命令 |
|------|------|----------|
| [shadowsocks](shadowsocks/) | Shadowsocks 全功能一键安装与管理（Debian 9-13 / Ubuntu / RHEL） | `bash <(curl -fsSL https://raw.githubusercontent.com/JXAB/CommonUserScripts/main/shadowsocks/install.sh)` |
| [cus](cus/) | CommonUserScripts V2 — 跨平台 OS-Aware 环境安装与调度引擎（8 大一键场景） | `curl -fsSL https://raw.githubusercontent.com/JXAB/CommonUserScripts/main/cus/install.sh -o /tmp/cus-install.sh && bash /tmp/cus-install.sh` |

各目录下均有独立 README，包含完整使用说明。
